**DendroIDE CODE** is more than a technology brand. It represents
the connection between identity, creativity and software development.

### Where does the name come from?

**DEN** comes from Dennis, while **DRO** comes from Leandro.

**IDE** is inspired by the beginning of our passion for technology
and Android application development, while also connecting with the
concept of an Integrated Development Environment.

**CODE** represents what brings everything together:
programming, software and technology.
